### `ActivityStyle`

| Variant | Payload | Description |
| ------- | ------- | ----------- |
| `Standard` | — | Full presentation — Lock Screen banner + Dynamic Island on iOS, full ongoing notification with custom RemoteViews on Android. |

### `AlertConfig`

Optional alert to fire alongside an activity update.

On iOS the platform decides whether to actually surface the alert
(respects Focus modes, do-not-disturb, etc.); on Android it becomes
a heads-up notification tied to the ongoing activity.

| Field | Wire | Type | Description |
| ----- | ---- | ---- | ----------- |
| `title` | `title` | `String` | Short title shown as the alert headline. |
| `body` | `body` | `String` | Body copy displayed under the title. |
| `sound` | `sound` | `AlertSound` | Which sound to play with the alert. |

### `DismissalPolicy`

| Variant | Payload | Description |
| ------- | ------- | ----------- |
| `Immediate` | — | Remove the activity immediately, no lingering final state. |
| `Default` | — | Platform default — iOS keeps the activity visible for a few minutes, Android leaves the ongoing notification until the system prunes it. |
| `AfterSeconds` | `u32` | Keep the final state visible for the given number of seconds, then remove. |
