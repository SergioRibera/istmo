### `AutostartState`

Whether the app starts at login.

| Variant | Payload | Description |
| ------- | ------- | ----------- |
| `Enabled` | — | Registered and allowed to run. |
| `Disabled` | — | Not registered. |
| `RequiresApproval` | — | macOS: registered, waiting for the user in System Settings (also what macOS reports once the user turned the login item off). |
| `DisabledByUser` | — | Registered, but the user turned it off in the system settings. Only the user turns it back on; [`Autostart::enable`] opens the settings page. |
| `DisabledByPolicy` | — | An administrator policy keeps it off. |
| `EnabledByPolicy` | — | An administrator policy keeps it on; [`Autostart::disable`] cannot turn it off. |
| `Unsupported` | — | This platform (or this build) has no autostart. |
